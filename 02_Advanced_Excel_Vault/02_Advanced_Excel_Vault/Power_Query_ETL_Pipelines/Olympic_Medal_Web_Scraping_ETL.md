# Web ETL Pipeline: 2020 Summer Olympics Data Ingestion Engine

## 📌 Domain Context
Analyzing macro-level international sports performance requires extracting public web datasets that are inherently fluid, unstructured, and prone to formatting shifts. This production pipeline connects directly to Wikipedia’s live HTML DOM engine, web-scrapes the 2020 Summer Olympics medal distribution matrix, resolves structural row anomalies, and implements custom performance indexing to build an analytical dataset optimized for downstream BI visualization layers.

## ⚙️ Data Engineering Architecture (Transformations Applied)
This Power Query script converts a highly nested HTML web matrix into a clean, relational table via the following programmatic steps:

* **Targeted HTML DOM Parsing:** Employs precise CSS selectors to isolate the core athletic table object (`TABLE.wikitable.sortable`), safely discarding peripheral page scripts, site navigation frames, and layout sidebars.
* **Character Cleansing & Regularization:** Cleans the `Country` dimensional string by identifying and stripping out structural metadata flags (such as the trailing `*` used to denote host country mutations), ensuring clean primary-key join compatibility.
* **Structural Void Imputation:** Applies a look-ahead optimization algorithm (`Table.FillUp`) on the `Rank` dimension to eliminate cell nulls caused by structural HTML row-spans where multiple nations shared an identical placement.
* **Advanced Feature Engineering (Linear Combination Matrix):** Rejects the standard "Total Medal Count" metric due to raw volume bias (which weights a Bronze medal identically to a Gold). Instead, it injects an advanced engineering calculation to produce the continuous metric `Weighted_Performance_Index`: 
  $$\text{Index} = (\text{Gold} \times 3) + (\text{Silver} \times 2) + (\text{Bronze} \times 1)$$
* **Categorical Cohort Segmentation:** Establishes deep conditional branching logic based on the continuous index, dividing records into distinct categorical buckets (`Global Powerhouse`, `Major Contender`, `Regional Competitor`) to enable rapid dashboard slicing.
* **Schema Enforcement & Filtering:** Assures mathematical integrity by converting continuous values into strict data types (`Percentage.Type`, `Int64.Type`) and permanently filters out the non-atomic summary footer meta-row (`Totals (93 entries)`) to guarantee downstream calculations never suffer from double-counting errors.
